命令 `uv run astercode supply-chain verify --root . --allow-dirty` 和等价脚本均返回 exit code `2`，状态为 `blocked`。最新 artifact 目录为：

`.astercode/artifacts/supply-chain/c52fa728febc-20260825T114125Z-c619da37/`

```text
content_pinned=true
sbom_generated=true
vulnerability_policy_passed=false
signature_verified=false
```

这表示精确镜像和 SBOM 证据已生成，但本机没有获批的 Trivy 数据库 provenance 和 Cosign trust anchor；工具 `DETECTED`、digest 固定或本地文件 hash 都不会被写成漏洞门/签名通过。

不带 `--allow-dirty` 的正式入口也按预期在生成前拒绝当前 dirty worktree；只有提交后的 clean target 才能进入正式发布证据流程。
